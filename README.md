# 🏠 House Price Prediction & Valuation Tool
A Machine Learning based web application that predicts house prices using the Ames Housing Dataset and XGBoost Regression Model.
---
## 🚀 Project Overview
This project focuses on building an end-to-end House Price Prediction system with:
- Data preprocessing
- Feature engineering
- Machine Learning model training
- SHAP explainability analysis
- Interactive Streamlit web application
The application allows users to input house details and receive predicted house prices instantly.
